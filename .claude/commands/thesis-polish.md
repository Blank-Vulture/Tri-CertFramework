# 文章推敲

指定されたテキストを学術論文として適切な表現に推敲する。

## 対象テキスト
$ARGUMENTS （直接テキストを入力、またはファイルパス）

## 推敲の観点

### 1. 文体の統一
- 「である調」への変換
- 主語の明確化（「本研究では」「本システムは」）
- 受動態の適切な使用

### 2. 冗長性の排除
- 不要な言葉の削除
- 重複表現の統合
- 簡潔な表現への置換

### 3. 学術的表現への変換
| 避けるべき表現 | 推奨表現 |
|--------------|---------|
| とても、非常に | 極めて、顕著に |
| 〜だと思う | 〜と考えられる |
| 〜したい | 〜することが望ましい |
| いろいろな | 様々な、多様な |
| ちゃんと | 適切に、正確に |
| 〜してみた | 〜を実施した |

### 4. 論理的接続の強化
- 段落間の繋がりを明確に
- 接続詞の適切な使用
- 因果関係の明示

### 5. 専門用語の確認
- 初出時の説明があるか
- 一貫した表記になっているか

## 出力形式

```
## 推敲結果

### 原文
[入力テキスト]

### 推敲後
[推敲したテキスト]

### 変更点
1. [変更箇所]: [理由]
2. ...
```
