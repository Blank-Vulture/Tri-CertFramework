## 修士論文

### 文書の真正性検証フレームワークの設計と実装
**ゼロ知識証明を用いた分散型証明システム Tri-CertFramework**

本論文では、ゼロ知識証明（ZK-SNARK）とWebAuthn署名を組み合わせた、新しい文書真正性検証フレームワークを提案します。

| 情報 | 内容 |
|------|------|
| **提出先** | 神戸情報大学院大学 情報技術研究科 |
| **分野** | 情報セキュリティ、暗号技術 |
| **キーワード** | ゼロ知識証明、WebAuthn、デジタル証明書、真正性検証 |
