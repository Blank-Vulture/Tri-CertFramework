# 内容梗概生成

論文全体を読み込み、修士論文構成例に準拠した内容梗概を生成する。

## 内容梗概の要件（構成例より）

> 内容梗概は、論文の全体像を分かりやすく、簡潔にまとめて記述する。
> どのような課題（問題点）があり、それを解決するために、著者は何を提案し、
> どのように実施し、課題解決を図ったのか、記述する。また、得られた成果を簡単に記述する。

## 構成要素

1. **背景・課題**: 何が問題なのか（2-3文）
2. **提案**: 著者は何を提案したか（2-3文）
3. **方法**: どのように実施したか（2-3文）
4. **成果**: 何が得られたか（2-3文）

## 制約
- 文字数: 400-600字程度
- 図表は含めない
- 専門用語は最小限に
- 論文を読んでいない人にも理解できる平易さ

## 出力形式

```
## 内容梗概

[生成した内容梗概]

---
文字数: XXX字
```
