:::tip[For Test Participants]
This guide explains how to use **Prover** (proof generation) and **Verifier** (verification).  
Please have the test PDF you received by email ready.
:::

## Testing Overview

| Step | Action | Description |
|:----:|--------|-------------|
| **1** | 📄 **Prover** | Attach proof to test PDF |
| **2** | 💾 **Save** | Download proof-attached PDF |
| **3** | ✅ **Verifier** | Verify PDF and check results |

---

## How to Use Prover

<div class="app-launch-card prover">
  <div class="app-launch-icon">📄</div>
  <div class="app-launch-content">
    <h4>Prover Application</h4>
    <p>Attach ZK proof to your certificate</p>
  </div>
  <a href="/Tri-CertFramework/prover/" target="_blank" class="app-launch-button">Open Prover →</a>
</div>

### Step 1: Upload PDF

Drag and drop the test PDF file you received by email, or click to select it.

### Step 2: Generate Proof

Click the "Generate Proof" button. Processing takes a few seconds to tens of seconds.

### Step 3: Check Progress

Five steps will proceed in order:
- Upload
- Hash calculation
- Proof generation
- Signature
- Export

### Step 4: Download

When complete, the proof-attached PDF will be downloaded automatically. **Save this file.**

## How to Use Verifier

<div class="app-launch-card verifier">
  <div class="app-launch-icon">✅</div>
  <div class="app-launch-content">
    <h4>Verifier Application</h4>
    <p>Verify the authenticity of your certificate</p>
  </div>
  <a href="/Tri-CertFramework/verifier-ui/" target="_blank" class="app-launch-button">Open Verifier →</a>
</div>

### Step 1: Upload Proof-attached PDF

Drag and drop the proof-attached PDF created with Prover, or click to select it.

### Step 2: Run Verification

Click the "🔍 Verify" button.

### Step 3: Check Results

If all 5 verification items show green ✅, it's a success.

---

## Success Criteria

Success is when all 5 items below show ✅ (green) in Verifier:

| Verification Item | Description |
|------------------|-------------|
| ✅ Data Extraction | Proof data read from PDF |
| ✅ Hash Match | PDF content not tampered |
| ✅ ZK Proof Verification | Zero-knowledge proof is valid |
| ✅ Signature Verification | Digital signature is valid |
| ✅ Registration Check | Issuer information confirmed |

:::caution[Important]
If any item shows ❌, please contact the test administrator.
:::

## FAQ

### Q: Proof generation takes a long time

**A:** The first time may take 30 seconds to 1 minute due to WASM file loading. Subsequent runs will be faster.

### Q: Getting errors during verification

**A:** Make sure you're using the PDF generated by Prover. **The original test PDF cannot be verified.**

### Q: Can I use it on a smartphone?

**A:** Yes, it is supported. However, proof generation requires processing power, so PC use is recommended.

### Q: What browsers are recommended?

**A:** We recommend the following browsers:
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+
