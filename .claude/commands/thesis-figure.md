# 図表作成支援

論文に挿入する図表の作成を支援する。

## 対象
$ARGUMENTS （例: システム構成図、シーケンス図、検証結果グラフ）

## 支援内容

### 1. Mermaid図の生成
論文に適した形式でMermaid記法の図を生成する。

**対応する図の種類:**
- フローチャート（処理フロー）
- シーケンス図（コンポーネント間通信）
- クラス図（データ構造）
- 状態遷移図
- アーキテクチャ図

### 2. 表のMarkdown生成
データを整理した表を生成する。

**対応する表の種類:**
- 比較表（既存手法との比較）
- 仕様表（システム要件）
- 結果表（検証結果）
- 環境表（開発環境）

### 3. キャプションの提案
図表に適切なキャプションを提案する。

## 出力形式

```markdown
## 図X.Y: [キャプション]

[Mermaid記法またはMarkdown表]

### 説明文案
[本文で図表を説明する文章]

### 配置推奨箇所
[章・節の指定]
```

## 論文での図表参照ルール
- 図は「図X.Y」で参照（Xは章番号、Yは章内の通し番号）
- 表は「表X.Y」で参照
- 必ず本文で図表に言及してから配置する
