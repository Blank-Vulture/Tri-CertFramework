年度ごとの検証鍵を生成するプロセスは以下の通りである：

1. **回路ファイル準備**: Circomで記述されたZKP回路をコンパイル
2. **WASM/ZKey生成**: ブラウザで実行可能なWASMファイルと証明鍵を生成
3. **VKハッシュ計算**: 検証鍵のSHA3-256ハッシュを計算
4. **バンドル作成**: マニフェストファイルとともにZIPアーカイブを作成
5. **Ledger署名**: ハードウェアウォレットでZIPのハッシュに署名

### VK生成画面

図3.6 にVK生成画面を示す。

![VK生成画面](executive-console/vk_generator.png)

管理者は年度を選択し、「生成」ボタンを押すことでVKバンドルの生成を開始する。生成には数分を要し、進捗状況がリアルタイムで表示される。

### バンドル生成完了画面

図3.7 にバンドル生成完了画面を示す。

![VKバンドル生成完了](executive-console/vk_generated.png)

生成が完了すると、VKバンドルのハッシュ値とLedger署名が表示される。管理者はこの情報を確認し、GitHubリポジトリにアップロードする。

### Ledger署名プロセス

VKバンドルの署名には、ハードウェアウォレットLedgerを使用する。図3.8〜3.13 にLedger署名プロセスを示す。

![Ledger署名待機画面](executive-console/hw-wallet/waiting_sign_task.png)

![Ledger署名タスク受信](executive-console/hw-wallet/received_sign_task.png)

Ledgerデバイスが接続されると、署名タスクがデバイスに送信される。

![署名詳細確認（1/2）](executive-console/hw-wallet/sign_details_1.png)

![署名詳細確認（2/2）](executive-console/hw-wallet/sign_details_2.png)

管理者はLedgerの画面でハッシュ値を確認し、物理ボタンで署名を承認する。

![署名確認](executive-console/hw-wallet/sign_confirm.png)

![署名完了](executive-console/hw-wallet/signed_message.png)

この物理的な承認プロセスにより、秘密鍵がLedgerの外部に出ることなく、安全に署名が行われる。
