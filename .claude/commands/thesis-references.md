# 参考文献管理

論文内の引用と参考文献リストの整合性を確認し、不足している文献を提案する。

## チェック内容

### 1. 引用の検証
- 本文中の [番号] が参考文献リストに存在するか
- 参考文献リストの文献が本文で引用されているか
- 引用番号の連続性（抜けや重複がないか）

### 2. 文献フォーマット
- 著者名, "タイトル", 出典, 年 の形式になっているか
- Webページの場合、アクセス日が記載されているか
- 日本語文献と英語文献の表記統一

### 3. 追加文献の提案
指定されたトピックについて、引用すべき重要な文献を提案する。

## 対象トピック（オプション）
$ARGUMENTS

## 出力形式

```
## 参考文献チェック結果

### 引用の問題
- [番号]: [問題内容]

### 未使用の文献
- [番号]: [文献情報]

### フォーマットの修正
- [番号]: [修正前] → [修正後]

### 追加推奨文献
1. 著者, "タイトル", 出典, 年
   - 引用推奨箇所: [章・節]
   - 理由: [なぜこの文献が必要か]
```
