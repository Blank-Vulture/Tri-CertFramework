# 第2章 先行研究と技術基盤

本章では、本研究の基盤となる技術と関連研究について述べる。まず、本章で使用する主要な用語を表2.0に示す。

<p align="center"><strong>表2.0: 本章で使用する主要用語</strong></p>

| 用語 | 説明 |
|------|------|
| ZKP（ゼロ知識証明） | ある命題が真であることを、その命題以外の情報を明かさずに証明する暗号技術 |
| zk-SNARKs | Zero-Knowledge Succinct Non-Interactive Argument of Knowledgeの略。簡潔で非対話的なゼロ知識証明方式 |
| Groth16 | zk-SNARKsの代表的なプロトコル。証明サイズが小さく検証が高速 |
| Poseidon | ZKP回路に最適化されたハッシュ関数。SHA-256と比較して回路サイズが小さい |
| WebAuthn | Web Authentication APIの略。パスワードレス認証のW3C標準規格 |
| FIDO2 | Fast IDentity Online 2の略。WebAuthnとCTAPから構成される認証規格 |
| CTAP | Client to Authenticator Protocolの略。クライアントと認証器間の通信プロトコル |
| VK（Verification Key） | ZKP検証に使用する公開鍵。証明の正当性を検証するために必要 |
| PKI | Public Key Infrastructureの略。公開鍵暗号を用いた認証基盤 |
| X.509 | ITU-Tが定めたデジタル証明書の標準規格 |

以下、2.1節ではデジタル証明書の現状と課題を、2.2節ではゼロ知識証明の基礎理論を、2.3節ではWebAuthnとFIDO2の技術仕様を、2.4節では関連研究を、2.5節では本研究のポジショニングを述べる。
