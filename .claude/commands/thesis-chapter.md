# 章別執筆支援

指定された章について、構成例に基づいた執筆支援を行う。

## 対象章
$ARGUMENTS （1-6の数字、または「序論」「先行研究」などの章名）

## 章別ガイドライン

### 第1章 序論
**必須要素:**
- 研究の背景・課題・動機
- 研究に至った経緯
- 研究の目的（明確に）
- Point of View（強調点・特徴）
- 論文の全体構造

**チェックポイント:**
- [ ] 社会的背景から個別の研究課題への流れが自然か
- [ ] 「なぜこの研究が必要か」が明確か
- [ ] 読者が興味を持つポイントが示されているか

### 第2章 先行研究
**必須要素:**
- 関連分野の既存研究のレビュー
- 各研究の概要と限界
- 本研究との差異の明確化

**チェックポイント:**
- [ ] 十分な数の文献を調査しているか
- [ ] 批判的な視点で分析しているか
- [ ] 本研究の新規性が浮き彫りになるか

### 第3章 解決策・設計・実装
**必須要素:**
- 課題の解決策（アイデア）
- システム構成と各機能
- 設計方法・仕様
- 開発環境・手法
- 実装の詳細

**チェックポイント:**
- [ ] 「発想」の部分が明確か
- [ ] 技術的な選択の根拠があるか
- [ ] 図表で視覚的に説明しているか

### 第4章 検証
**必須要素:**
- 検証方法の説明
- 検証結果（数値・グラフ）
- セキュリティ評価
- 既存手法との比較

**チェックポイント:**
- [ ] 客観的なデータを示しているか
- [ ] 統計的な分析があるか
- [ ] 予定どおりでない部分の説明があるか

### 第5章 考察
**必須要素:**
- 提案手法の論評
- 長所・短所の分析
- 反省点
- 残された課題

**チェックポイント:**
- [ ] 検証結果に基づいた議論か
- [ ] 客観的な自己評価ができているか
- [ ] 今後の改善方向が示されているか

### 第6章 結論
**必須要素:**
- 研究の総まとめ
- 得られた結論
- 成果の強調
- 今後の計画

**チェックポイント:**
- [ ] 序論の目的に対応しているか
- [ ] 新規性・貢献が明確か
- [ ] 読後感が良いか

## 出力

指定された章について:
1. 現状の評価
2. 不足している要素
3. 改善・追加すべき内容
4. 具体的な文章案
