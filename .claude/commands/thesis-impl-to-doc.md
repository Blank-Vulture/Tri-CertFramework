# 実装から論文記述生成

指定されたソースコードを解析し、論文に記載すべき内容を生成する。

## 対象
$ARGUMENTS （例: prover/src/app, circuits/commitment.circom, registrar-console）

## 生成内容

### 1. システム構成図の素材
- コンポーネント間の関係
- データフローの説明
- 依存関係

### 2. 実装詳細の論文記述
- 使用技術の説明
- 主要な処理フローの解説
- 重要な設計判断とその理由

### 3. アルゴリズム説明
- 処理の流れを日本語で記述
- 疑似コードへの変換（必要に応じて）
- 計算量・セキュリティ特性

### 4. 図表の提案
- 必要なアーキテクチャ図
- シーケンス図
- データ構造図

## 出力形式

```markdown
## [コンポーネント名] の論文記述

### システム構成
[構成の説明]

### 実装詳細
[詳細な説明]

### 主要な処理フロー
1. [ステップ1]
2. [ステップ2]
...

### 設計判断
| 判断内容 | 選択肢 | 採用理由 |
|---------|-------|---------|
| ... | ... | ... |

### 推奨図表
- 図: [種類] - [内容の説明]
```
