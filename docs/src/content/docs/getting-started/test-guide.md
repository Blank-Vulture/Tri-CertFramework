このガイドでは、**Prover**（証明生成）と**Verifier**（検証）の使い方を説明します。  
メールで受け取ったテスト用PDFをご用意ください。
:::

## テストの全体像

| Step | 操作 | 説明 |
|:----:|------|------|
| **1** | 📄 **Prover** | テスト用PDFに証明を添付 |
| **2** | 💾 **保存** | 証明付きPDFをダウンロード |
| **3** | ✅ **Verifier** | PDFを検証して結果を確認 |

---

## Proverの使い方

<div class="app-launch-card prover">
  <div class="app-launch-icon">📄</div>
  <div class="app-launch-content">
    <h4>Prover アプリケーション</h4>
    <p>証明書にZK証明を添付します</p>
  </div>
  <a href="/Tri-CertFramework/prover/" target="_blank" class="app-launch-button">Proverを開く →</a>
</div>

### Step 1: PDFをアップロード

メールで受け取ったテスト用PDFファイル、またはご自身で用意されたPDFをドラッグ＆ドロップ、またはクリックして選択します。

### Step 2: 証明を生成

「証明を生成」ボタンをクリックします。処理には数秒〜数十秒かかります。

### Step 3: 進捗を確認

5つのステップが順番に進みます：
- アップロード
- ハッシュ計算
- 証明生成
- 署名
- エクスポート

### Step 4: ダウンロード

完了すると証明付きPDFがダウンロードできるボタンが表示されます。**このボタンを押してファイルを保存してください。**
ここで保存されたファイルが「元のファイル名＋-secured.pdf」となっていることを確認してください。

## Verifierの使い方

<div class="app-launch-card verifier">
  <div class="app-launch-icon">✅</div>
  <div class="app-launch-content">
    <h4>Verifier アプリケーション</h4>
    <p>証明書の真正性を検証します</p>
  </div>
  <a href="/Tri-CertFramework/verifier-ui/" target="_blank" class="app-launch-button">Verifierを開く →</a>
</div>

### Step 1: 証明付きPDFをアップロード

Proverで作成した証明付きPDFファイルをドラッグ＆ドロップ、またはクリックして選択します。

### Step 2: 検証を実行

「🔍 検証」ボタンをクリックします。

### Step 3: 結果を確認

5つの検証項目がすべて緑色 ✅ になれば成功です。

---

## 成功の判定基準

Verifierで以下の5項目がすべて ✅（緑色）になれば成功です：

| 検証項目 | 説明 |
|---------|------|
| ✅ データ抽出 | PDFから証明データを読み取れた |
| ✅ ハッシュ照合 | PDFの内容が改ざんされていない |
| ✅ ZK証明検証 | ゼロ知識証明が有効 |
| ✅ 署名検証 | 電子署名が有効 |
| ✅ 登録確認 | 発行者情報が確認できた |

:::caution[重要]
1つでも ❌ がある場合は、テスト担当者にご連絡ください。
:::

## よくある質問

### Q: 証明の生成に時間がかかる

**A:** 初回はWASMファイルの読み込みがあるため、30秒〜1分程度かかることがあります。2回目以降は高速になります。

### Q: 検証でエラーが出る

**A:** Proverで生成したPDFと異なるファイルを使用していないか確認してください。**元のテスト用PDFでは検証できません。**

### Q: スマートフォンでも使える？

**A:** はい、対応しています。ただし、証明生成には処理能力が必要なため、PCの使用を推奨します。

### Q: ブラウザの推奨環境は？

**A:** 以下のブラウザを推奨します：
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+
