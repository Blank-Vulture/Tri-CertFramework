# 論文提出前チェックリスト

論文全体を読み込み、提出前の最終チェックを行う。

## チェック項目

### 形式面
- [ ] 表紙情報（タイトル、所属、氏名、学籍番号、提出日）
- [ ] 内容梗概の有無と適切さ
- [ ] 目次の整合性
- [ ] ページ番号
- [ ] 図表番号の連続性
- [ ] 参考文献の形式統一

### 内容面
- [ ] 序論で提示した目的が結論で達成されているか
- [ ] 各章の分量バランス
- [ ] Point of Viewが明確に示されているか
- [ ] 先行研究との差異が明確か
- [ ] 検証結果が主張を裏付けているか

### 表記面
- [ ] 「である調」の統一
- [ ] 誤字脱字
- [ ] 専門用語の初出説明
- [ ] 英語表記の統一

### 構成例との照合
修士論文構成例.pdfの要件を満たしているか確認
