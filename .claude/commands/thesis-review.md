# 論文章レビュー

指定された章のMarkdownファイルを読み込み、以下の観点から詳細なレビューを行う。

## レビュー対象
$ARGUMENTS （例: 第1章、第3章 3.2節、全体）

## レビュー観点

### 1. 構成・論理性
- 章の流れは論理的か
- 各段落の繋がりは自然か
- 主張と根拠の対応は明確か

### 2. 学術的表現
- 「である調」で統一されているか
- 曖昧な表現（「など」「といった」の多用）はないか
- 専門用語の初出時に説明があるか

### 3. 内容の充実度
- 主張に十分な根拠があるか
- 具体例やデータが示されているか
- 先行研究との差異が明確か

### 4. 修士論文構成例との整合性
- 構成例で求められている要素が含まれているか
- 記載すべき内容が不足していないか

## 出力形式

```
## レビュー結果: [章名]

### 良い点
- ...

### 改善提案
1. [具体的な箇所]: [改善内容]
2. ...

### 追加すべき内容
- ...

### 修正案（該当箇所のみ）
```
